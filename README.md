# 🌤 Telegram-бот погоды

Учебный индивидуальный проект по информатике (10 класс, Лицей №7)

## 📌 Описание
Бот предоставляет:
- Текущую погоду по городу (`/weather Москва`)
- Прогноз на 5 дней с агрегацией данных (`/forecast Париж`)
- Обработку ошибок и русский язык в описаниях

## 🛠 Технологии
- Python 3.10+
- `python-telegram-bot` (v20+)
- `requests`, `httpx`
- OpenWeatherMap API

## 🚀 Запуск
1. `git clone https://github.com/ВАШ_НИК/weather-telegram-bot.git`
2. `cd weather-telegram-bot`
3. `pip install -r requirements.txt`
4. Скопируйте `config.py.example` → `config.py`, вставьте токены
5. `python school.py`
